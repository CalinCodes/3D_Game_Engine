## 📌 Project Overview

**3D Game Engine** is a custom-built rendering engine developed in **C++
using OpenGL**, created as part of the **Gameloft Game Development
Workshop 2024**.

The project focuses on understanding the internal architecture of
real-time graphics engines by implementing core systems such as
rendering, resource management, and scene handling from scratch.

This repository serves both as a learning project and as a technical
foundation for experimenting with real-time 3D graphics concepts.

## 🎯 Objectives

-   Gain hands-on experience with modern graphics programming.
-   Understand how a game engine pipeline works internally.
-   Implement rendering and asset workflows without relying on existing
    engines.
-   Explore shader-based rendering and GPU interaction.
-   Build a modular structure suitable for future extensions (physics,
    input, gameplay logic).

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   **C++** - Core engine implementation
-   **OpenGL** - Real-time rendering API
-   **GLSL / HLSL (Shaders)** - GPU shading programs
-   **XML assets** - Supporting configuration and structured data
